NUST Hostel Menu

A full-stack hostel meal dashboard developed for NUST students. The system displays upcoming meals and provides weekly menu predictions, helping students know what meals are likely to be available in advance. Meal information is stored in a MySQL database and accessed through a PHP backend.

Hostess

A full-stack web application that helps users discover affordable short-term guest house accommodation in Windhoek. Users can browse available guest houses, filter them by amenities and location, and view prices and property information. Property owners can also add new guest houses through the platform, with information stored in a MySQL database and retrieved through a Node.js API.Hosted using render, aiven for the database and cloudinary for the permanent storage of images

HTML CSS JavaScript Node.js Express.js MySQL REST API Cloudinary Aiven Render

Software Verification & Validation

A software testing module where our team tested a client's application to identify functional defects, UI issues, and unexpected system behaviour. We designed and executed test cases, performed unit testing using JUnit, and used Chrome DevTools to inspect and troubleshoot application behaviour. Bugs were documented with test results and supporting evidence in Excel, while Trello was used to track testing tasks and identified issues. The project concluded with a technical report and presentation of our findings, defects, and recommendations to the client.
